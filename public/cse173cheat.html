Mathematical Induction — The Template (memorize this!)
1. P(n): State what you're proving. 2. Basis: Show P(1) [or P(base)] is true. ← don't skip, even if obvious 3. IH: Assume P(k) is true for some arbitrary positive integer k. 4. IS: Using the IH, show P(k+1) is true. 5. Conclude: Therefore P(n) holds for all n ≥ base. □

Pigeonhole Principle
Basic: k+1 items in k boxes → ≥1 box has ≥ 2 items Generalized: N items in k boxes → ≥1 box has ≥ ⌈N/k⌉ items Guarantee m in group of k: Need N = (m−1)·k + 1

Counting Relations
Relations from A to B = 2^(|A| × |B|) Subsets of a set with n elements = 2ⁿ Example: |A|=5, |B|=6 → 2^(5×6) = 2^30

Hasse Diagrams
Steps to draw: 1. Start with digraph of partial order 2. Remove loops (reflexive edges) 3. Remove edges implied by transitivity (if a→b→c exists, remove a→c) 4. Arrange lower elements below higher 5. Remove all arrowheads
