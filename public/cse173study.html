Mathematical Induction · Strong Induction · Recursive Definitions
Mathematical Induction — The Template
This is the #1 exam topic — Quiz 3 SET C Q1 was entirely this. Memorize the structure.
1. State P(n): what you're proving. 2. Basis Step: Show P(1) [or P(base)] is true. 3. Inductive Hypothesis (IH): Assume P(k) is true for some arbitrary k. 4. Inductive Step: Show P(k) → P(k+1) is true. 5. Conclusion: Therefore P(n) holds for all n ≥ base. □
Proof TypeKey Manipulation
Summation
1+2+…+n = n(n+1)/2		 Add the (k+1) term to both sides of IH, factor out (k+1)
Divisibility
6ⁿ−1 divisible by 5		 Expand 6^(k+1)−1 = 6·6ᵏ−1, substitute IH, factor out 5
Inequality
n < 2ⁿ		 Use IH k < 2ᵏ, then k+1 < 2ᵏ+1 ≤ 2·2ᵏ = 2^(k+1)
Geometric series
1+2+…+2ⁿ = 2^(n+1)−1		 Add 2^(k+1) to IH, simplify to 2^(k+2)−1
Classic Divisibility Worked Example
Prove: 6ⁿ − 1 is divisible by 5 for all positive integers n. Basis: n=1 → 6¹−1 = 5 = 5·1 ✓ IH: Assume 5 | (6ᵏ−1), so 6ᵏ−1 = 5m for some integer m. IS: 6^(k+1) − 1 = 6·6ᵏ − 1 = 6(1 + 5m) − 1 [since 6ᵏ = 1+5m by IH] = 6 + 30m − 1 = 5 + 30m = 5(1 + 6m) ← divisible by 5 ✓ Conclusion: P(n) holds for all n ≥ 1. □
Strong Induction

Difference: IH assumes P(1) ∧ P(2) ∧ … ∧ P(k) (all previous cases, not just k). Use when P(k+1) depends on more than just P(k).

BASIS: Show P(1) [possibly P(1) through P(b)] true. IH: Assume P(j) is true for ALL j with 1 ≤ j ≤ k. IS: Show P(k+1) follows.

Permutations vs. Combinations
ORDER MATTERS (Permutations): P(n,r) = n!/(n−r)! = n(n−1)(n−2)…(n−r+1) With repetition: nʳ ORDER DOESN'T MATTER (Combinations): C(n,r) = n! / (r! · (n−r)!) ← also written as (n choose r) C(n,r) = C(n, n−r) ← symmetry property With repetition: C(n+r−1, r) Indistinguishable objects (like letters in a word): n! / (n₁! · n₂! · … · nₖ!)

Binomial Theorem & Pascal's Identity
(x+y)ⁿ = Σⱼ₌₀ⁿ C(n,j) · xⁿ⁻ʲ · yʲ Pascal's Identity: C(n,k) = C(n−1,k−1) + C(n−1,k) Sum of a row: Σⱼ₌₀ⁿ C(n,j) = 2ⁿ [set x=y=1] Useful symmetry: C(n,r) = C(n, n−r)
Counting Relations & Functions
Relations from A to B = 2^(|A| × |B|) Subsets of A = 2^|A| Functions from A to B = |B|^|A| One-to-one functions = |B|(|B|−1)(|B|−2)…(|B|−|A|+1) [need |B| ≥ |A|]

Properties · Matrix Representation · Equivalence Relations · Partial Orders · Hasse Diagrams
Four Properties — Quick Reference
Quiz 3 Spring 2019 Q2 was exactly this — check each property one by one and justify with examples.
PropertyDefinitionMatrix checkHow to disprove
Reflexive (a,a) ∈ R for ALL a ∈ A All diagonal = 1 Find any a with (a,a) ∉ R
Symmetric (a,b) ∈ R → (b,a) ∈ R Matrix = transposeᵀ Find (a,b) in R but (b,a) not
Antisymmetric (a,b) ∈ R and (b,a) ∈ R → a=b mᵢⱼ=0 or mⱼᵢ=0 when i≠j Find (a,b) and (b,a) where a≠b
Transitive (a,b) ∈ R and (b,c) ∈ R → (a,c) ∈ R R² ⊆ R Find (a,b),(b,c) in R but (a,c) not
Named Relation Types
EQUIVALENCE RELATION = Reflexive + Symmetric + Transitive → Equivalence classes [a] partition the set → [a] = {x ∈ A | (a,x) ∈ R} → [a] = [b] ↔ aRb PARTIAL ORDER (POSET) = Reflexive + Antisymmetric + Transitive → (S, R) is a "partially ordered set" → Total order: every two elements are comparable → Well-order: total order where every nonempty subset has a least element
Worked Example — Testing Properties
A = {a,b,c}, R = {(a,a),(b,b),(c,c),(a,b),(b,a)} Reflexive? YES — (a,a),(b,b),(c,c) all in R ✓ Symmetric? YES — (a,b) ∈ R and (b,a) ∈ R ✓ (and self-loops are trivially symmetric) Antisymmetric? NO — (a,b) and (b,a) both in R but a ≠ b ✗ Transitive? YES — (a,b)+(b,a)→need(a,a)✓, (b,a)+(a,b)→need(b,b)✓ ✓ → This is an EQUIVALENCE RELATION.
Hasse Diagrams
To draw a Hasse diagram from a partial order: 1. Start with the digraph of the relation 2. Remove all loops (reflexive property) 3. Remove edges implied by transitivity (if a→b→c, remove a→c) 4. Arrange so lower elements are physically below higher ones 5. Remove arrowheads (all edges point upward implicitly)
Counting Relations Formula
# relations from A to B = 2^(|A| × |B|) Example: |A|=5, |B|=6 → 2^(5×6) = 2^30 relations from A to B → 2^(6×5) = 2^30 relations from B to A
