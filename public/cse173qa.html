Mathematical Induction — Divisibility
Prove n³ − n is divisible by 3
Induction ⚡ High Probability
▾

Question: Use mathematical induction to prove that n³ − n is divisible by 3 for every positive integer n.

✓ Full Solution
P(n): n³ − n is divisible by 3. Basis Step (n=1): 1³ − 1 = 0 = 3·0. Divisible by 3. ✓ Inductive Hypothesis (IH): Assume 3 | (k³ − k) for some positive integer k. So k³ − k = 3m for some integer m. Inductive Step: Show (k+1)³ − (k+1) is divisible by 3. (k+1)³ − (k+1) = (k³ + 3k² + 3k + 1) − (k + 1) = k³ + 3k² + 3k + 1 − k − 1 = (k³ − k) + 3k² + 3k = (k³ − k) + 3(k² + k) By IH, (k³ − k) is divisible by 3. 3(k² + k) is clearly divisible by 3. ∴ Their sum is divisible by 3. ✓ Conclusion: By mathematical induction, P(n) holds for all n ≥ 1. □

Mathematical Induction — Summation Formula
Prove 1 + 2 + … + n = n(n+1)/2
Induction ⚡ High Probability
▾

Question: Use mathematical induction to prove that 1 + 2 + 3 + … + n = n(n+1)/2 for all positive integers n.

✓ Full Solution
Basis Step (n=1): LHS = 1. RHS = 1(2)/2 = 1. ✓ Inductive Hypothesis (IH): Assume 1+2+…+k = k(k+1)/2. Inductive Step: Show 1+2+…+k+(k+1) = (k+1)(k+2)/2. LHS = [1+2+…+k] + (k+1) = k(k+1)/2 + (k+1) [by IH] = (k+1)[k/2 + 1] = (k+1)(k+2)/2 = RHS ✓ Conclusion: Holds for all positive integers n. □

Mathematical Induction — Geometric Series

Induction ⚡ Appeared in Quiz 3 SET C

Question: Use mathematical induction to show that 1 + 2¹ + 2² + 2³ + … + 2ⁿ = 2ⁿ⁺¹ − 1.

✓ Full Solution
Basis Step (n=0): LHS = 1. RHS = 2¹ − 1 = 1. ✓ Inductive Hypothesis (IH): Assume 1+2+4+…+2ᵏ = 2^(k+1) − 1. Inductive Step: Show 1+2+…+2ᵏ+2^(k+1) = 2^(k+2) − 1. LHS = [1+2+4+…+2ᵏ] + 2^(k+1) = (2^(k+1) − 1) + 2^(k+1) [by IH] = 2 · 2^(k+1) − 1 = 2^(k+2) − 1 = RHS ✓ Conclusion: Holds for all n ≥ 0. □

Recursive Function Evaluation
Compute f(3), f(4) and identify recursion
Recursion ⚡ Appeared in Quiz 3 Spring 2019
▾

Question: A function f is defined as: f(1) = 3, f(2) = 6, and 2f(n+1) = 4f(n) − 2f(n−1).

Find f(3) and f(4). Is this function recursive?

✓ Full Solution
Finding f(3): 2f(3) = 4f(2) − 2f(1) = 4(6) − 2(3) = 24 − 6 = 18 ∴ f(3) = 9 Finding f(4): 2f(4) = 4f(3) − 2f(2) = 4(9) − 2(6) = 36 − 12 = 24 ∴ f(4) = 12 Is it recursive? YES. Reason: 1. Has explicit base cases: f(1) = 3 and f(2) = 6 are defined directly. 2. Has a recursive rule: f(n+1) is defined in terms of f(n) and f(n−1), which are smaller inputs. Both components of a recursive definition are present. ✓

Relation Properties
Test Reflexive, Symmetric, Antisymmetric, Transitive
Relations ⚡ Appeared in Quiz 3 Spring 2019
▾

Question: Given A = {a, b, c} and R = {(a,a), (b,b), (c,c), (a,b), (b,a)}. Determine (with justification) if R is Reflexive, Symmetric, Antisymmetric, and Transitive.

✓ Full Solution
Reflexive? YES ✓ Need (a,a),(b,b),(c,c) ∈ R. All three are present. ✓ Symmetric? YES ✓ For every (x,y) ∈ R, check (y,x) ∈ R: (a,b) ∈ R and (b,a) ∈ R ✓ Self-loops (a,a),(b,b),(c,c) trivially satisfy symmetry. ✓ Antisymmetric? NO ✗ (a,b) ∈ R and (b,a) ∈ R, but a ≠ b. Violates antisymmetry. Transitive? YES ✓ Check all pairs: (a,b)+(b,a) → need (a,a) ∈ R ✓ (b,a)+(a,b) → need (b,b) ∈ R ✓ All other paths use self-loops which trivially hold. ✓ Conclusion: R is an EQUIVALENCE RELATION (Reflexive + Symmetric + Transitive).

Counting Relations
How many relations from A to B and B to A?
Relations ⚡ Appeared in Quiz 3 Spring 2019
▾

Question: Given A = {a, b, c, d, e} and B = {1, 2, 3, p, q, r}. How many relations are possible from A to B? From B to A? Show your calculation.

✓ Full Solution
Key formula: Relations from A to B = 2^(|A| × |B|) Reason: A relation is any subset of A × B. |A × B| = |A| · |B|, and a set with n elements has 2ⁿ subsets. Given: |A| = 5, |B| = 6 Relations from A to B: |A × B| = 5 × 6 = 30 Number of relations = 2^30 = 1,073,741,824 Relations from B to A: |B × A| = 6 × 5 = 30 Number of relations = 2^30 = 1,073,741,824 Both are the same here because |A|×|B| = |B|×|A|.

Question (a): A committee of 4 must be chosen from 10 people. How many ways are there?

Question (b): In how many ways can the letters of the word BANANA be arranged?

✓ Full Solution
Part (a) — Committee (order doesn't matter → Combination): C(10,4) = 10! / (4! · 6!) = (10 × 9 × 8 × 7) / (4 × 3 × 2 × 1) = 5040 / 24 = 210 ways Part (b) — BANANA arrangements (indistinguishable objects): BANANA has 6 letters: B=1, A=3, N=2 Formula: n! / (n₁! · n₂! · … · nₖ!) = 6! / (1! · 3! · 2!) = 720 / (1 × 6 × 2) = 720 / 12 = 60 arrangements

Pigeonhole Principle
Guarantee same birthday month
Counting
▾

Question: How many students must be in a class to guarantee that at least 4 have birthdays in the same month?

✓ Full Solution
Setup: "Boxes" = 12 months "Objects" = students We want: at least one box has ≥ 4 objects. Using Generalized Pigeonhole Principle: We need ⌈N/12⌉ ≥ 4 The smallest N satisfying this: N = 3 × 12 + 1 = 37 Verification: With 36 students: worst case = exactly 3 per month (3×12=36). Not guaranteed. With 37 students: by pigeonhole, at least one month has ⌈37/12⌉ = ⌈3.08⌉ = 4. ✓ Answer: 37 students

Equivalence Relation — Modulo
Prove congruence mod 3 is an equivalence relation
Equivalence
▾

Question: Show that R = {(a,b) | a ≡ b (mod 3)} on the set of integers is an equivalence relation. List its equivalence classes.

✓ Full Solution
Recall: a ≡ b (mod 3) means 3 divides (a − b). Reflexive: a ≡ a (mod 3) since a − a = 0 = 3·0. ✓ Symmetric: Assume a ≡ b (mod 3). Then a − b = 3k for some integer k. So b − a = −3k = 3(−k), meaning 3 | (b−a). Therefore b ≡ a (mod 3). ✓ Transitive: Assume a ≡ b (mod 3) and b ≡ c (mod 3). Then a − b = 3k and b − c = 3m. Adding: a − c = 3k + 3m = 3(k+m). Therefore a ≡ c (mod 3). ✓ Conclusion: R is an equivalence relation. □ Equivalence classes: [0] = {…, −6, −3, 0, 3, 6, 9, …} (multiples of 3) [1] = {…, −5, −2, 1, 4, 7, 10, …} (remainder 1 when divided by 3) [2] = {…, −4, −1, 2, 5, 8, 11, …} (remainder 2 when divided by 3) These 3 classes partition the integers.
