1. Polymorphism

Polymorphism means "many forms." In Java, it allows a parent-class reference to point to a child-class object. The correct (child) version of an overridden method runs at runtime — this is called dynamic dispatch.

Key Rules

  • A parent reference can hold a child object: Animal a = new Dog();
  • The method called is determined by the actual object type, not the reference type.
  • Use @Override annotation when overriding a method.
  • The child method signature must exactly match the parent signature.
  • Child can call parent constructor with super(args).
  • Child can call parent method with super.methodName().

Method Overriding Example

class Animal {
    String name;
    Animal(String name) { this.name = name; }

    void makeSound() {
        System.out.println(name + " makes a sound.");
    }
}

class Dog extends Animal {
    Dog(String name) { super(name); }

    @Override
    void makeSound() {
        System.out.println(name + " says: Woof!");
    }
}

class Cat extends Animal {
    Cat(String name) { super(name); }

    @Override
    void makeSound() {
        System.out.println(name + " says: Meow!");
    }
}

// Main
Animal a1 = new Dog("Rex");  // parent ref, child object
Animal a2 = new Cat("Whiskers");
a1.makeSound();  // Woof! — resolved at RUNTIME
a2.makeSound();  // Meow!
Golden Rule: The reference type determines what methods you CAN call. The object type determines WHICH version runs.

2. Abstract Classes

What is an Abstract Class?

An abstract class is declared with the abstract keyword. It hides implementation details and shows only functionality. Think of it as an incomplete blueprint.

Key Rules for Abstract Classes

  • Use abstract keyword: abstract class MyClass { }
  • Cannot be instantiated — you cannot do new AbstractClass()
  • Must be inherited by another class using extends
  • Can have both abstract (no body) and concrete (with body) methods
  • Can have constructors, data fields, and regular methods
  • In UML diagrams, abstract classes and abstract methods are shown in Italics

What is an Abstract Method?

  • Declared with abstract keyword, no body, ends with ;
  • Example: public abstract void displayInfo();
  • Must be in an abstract class
  • Must be overridden in any concrete (non-abstract) subclass
  • Do NOT use final or static on abstract methods — final prevents overriding!
Cannot instantiate abstract class! Book b = new Book(); → COMPILE ERROR. You can only instantiate the concrete subclasses.

Abstract Class Syntax

abstract class ClassName {
    // data fields (same as normal class)
    private String field;

    // constructors (same as normal class)
    public ClassName() {}
    public ClassName(String field) { this.field = field; }

    // concrete method (has a body)
    public void setField(String f) { this.field = f; }
    public String getField() { return field; }

    // abstract methods (NO body, ends with ;)
    public abstract void displayInfo();
    public abstract boolean checkSomething(int value);
}

Book / FictionBook / NonFictionBook Example (From Lab)

// Abstract parent class
abstract class Book {
    private String name;
    private String author;

    public Book() {}

    public Book(String name, String author) {
        this.name = name;
        this.author = author;
    }

    public void setName(String name) { this.name = name; }
    public String getName() { return name; }
    public void setAuthor(String author) { this.author = author; }
    public String getAuthor() { return author; }

    // Abstract methods — subclasses MUST implement these
    public abstract void displayInfo();
    public abstract boolean isRecommendedForAge(int age);
}

// Concrete subclass 1
class FictionBook extends Book {
    private String genre;

    public FictionBook() {}

    public FictionBook(String name, String author, String genre) {
        super(name, author);   // calls Book(name, author) constructor
        this.genre = genre;
    }

    public void setGenre(String genre) { this.genre = genre; }
    public String getGenre() { return genre; }

    @Override
    public void displayInfo() {
        System.out.println(getName());    // use getter from parent
        System.out.println(getAuthor());
        System.out.println(genre);
    }

    @Override
    public boolean isRecommendedForAge(int age) {
        return age >= 14;    // FictionBook: 14 and above
    }
}

// Concrete subclass 2
class NonFictionBook extends Book {
    private String subject;

    public NonFictionBook() {}

    public NonFictionBook(String name, String author, String subject) {
        super(name, author);
        this.subject = subject;
    }

    public void setSubject(String subject) { this.subject = subject; }
    public String getSubject() { return subject; }

    @Override
    public void displayInfo() {
        System.out.println(getName());
        System.out.println(getAuthor());
        System.out.println(subject);
    }

    @Override
    public boolean isRecommendedForAge(int age) {
        return age >= 18;    // NonFictionBook: 18 and above
    }
}

3. Interfaces

What is an Interface?

An interface is a completely abstract type that defines what a class must do, but not how. It is a contract or blueprint of behavior.

Key Rules for Interfaces

  • Use interface keyword instead of class
  • Use implements (not extends) to use an interface in a class
  • Cannot be instantiated
  • A class can implement MULTIPLE interfaces (unlike extends which is single only)
  • All variables in interface are public static final by default
  • All methods in interface are public abstract by default
  • The implementing class MUST override all interface methods
  • Interfaces can extend other interfaces (using extends)

Interface Syntax

public interface InterfaceName {
    int CONSTANT = 10;           // public static final BY DEFAULT

    void methodA();              // public abstract BY DEFAULT
    String methodB(int x);       // public abstract BY DEFAULT
    public abstract void methodC();  // explicitly written (same as above)
}

// Implementing the interface
class MyClass implements InterfaceName {
    @Override
    public void methodA() {
        System.out.println("Implementation of methodA");
    }

    @Override
    public String methodB(int x) {
        return "Value: " + x;
    }

    @Override
    public void methodC() {
        System.out.println("Implementation of methodC");
    }
}

Pokemon Interface Example (From Lab)

// The Interface
interface Pokemon {
    void setName(String name);
    String getName();
    int getLevel();
    void levelUp();
    void attack();
    void displayInfo();
}

// FirePokemon implementing Pokemon
class FirePokemon implements Pokemon {
    private String name;
    private int level;

    public FirePokemon() {}

    public FirePokemon(String name, int level) {
        this.name = name;
        this.level = level;
    }

    @Override public void setName(String name) { this.name = name; }
    @Override public String getName() { return name; }
    @Override public int getLevel() { return level; }
    @Override public void levelUp() { level++; }

    @Override
    public void attack() {
        int choice = (int) Math.ceil(3 * Math.random());
        if (choice == 1)      System.out.println(name + " has used Ember");
        else if (choice == 2) System.out.println(name + " has used Fire Spin");
        else                  System.out.println(name + " has used Flame Charge");
    }

    @Override
    public void displayInfo() {
        System.out.println(name);
        System.out.println("Fire");
        System.out.println(level);
    }
}

Random choice formula: int choice = (int) Math.ceil(3 * Math.random());
Math.random() returns [0.0, 1.0) → multiplied by 3 gives [0, 3) → Math.ceil gives 0, 1, 2, or 3 → cast to int gives 0, 1, 2, or 3. Note: when Math.random() = 0, Math.ceil(0) = 0, so choice can be 0. 4. Exception Handling

Exception handling prevents the program from crashing when errors occur. It separates error-handling code from normal code.

try-catch-finally Structure

try {
    // Code that might throw an exception
    int result = 10 / 0;                // ArithmeticException
    String s = null;
    s.length();                         // NullPointerException
} catch (ArithmeticException e) {
    System.out.println("Math error: " + e.getMessage());
} catch (NullPointerException e) {
    System.out.println("Null error: " + e.getMessage());
} catch (Exception e) {
    // Catches ANY exception not caught above
    System.out.println("Error: " + e.getMessage());
} finally {
    // Always runs — use for cleanup (closing files, etc.)
    System.out.println("Finally block always executes");
}

Common Exception Types

ExceptionWhen it occurs
IOExceptionFile read/write errors
FileNotFoundExceptionFile does not exist
ArithmeticExceptionDivision by zero
NullPointerExceptionUsing null reference
ArrayIndexOutOfBoundsExceptionInvalid array index
NumberFormatExceptionInvalid number conversion

throws keyword

// Declare that a method can throw an exception
public static void readFile(String filename) throws IOException {
    BufferedReader reader = new BufferedReader(new FileReader(filename));
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
    reader.close();
}

// Caller must handle it
public static void main(String[] args) {
    try {
        readFile("data.txt");
    } catch (IOException e) {
        System.out.println("Could not read file.");
    }
}

5. File I/O (Input / Output)

File I/O allows Java programs to store data persistently in files. Data survives after the program ends.

Always import: import java.io.*;

Key Classes

ClassPurpose
FileRepresents a file or directory path
FileWriterWrites characters to a file
FileReaderReads characters from a file
BufferedWriterEfficiently writes text (wraps FileWriter)
BufferedReaderEfficiently reads text line by line (wraps FileReader)

Creating a File

try {
    File file = new File("student.txt");
    if (file.createNewFile()) {
        System.out.println("File created.");
    } else {
        System.out.println("File already exists.");
    }
} catch (IOException e) {
    System.out.println("Unable to create file.");
}

Writing to a File

try {
    BufferedWriter writer = new BufferedWriter(new FileWriter("student.txt"));
    writer.write("Name: Alex");
    writer.newLine();        // writes a newline character
    writer.write("ID: 12345");
    writer.newLine();
    writer.write("Dept: CSE");
    writer.close();          // ALWAYS close after writing!
    System.out.println("Student information saved successfully.");
} catch (IOException e) {
    System.out.println("Error writing file.");
}

Append Mode (add without overwriting)

// Pass 'true' as second argument to FileWriter for append mode
BufferedWriter writer = new BufferedWriter(new FileWriter("student.txt", true));

Reading from a File

try {
    BufferedReader reader = new BufferedReader(new FileReader("student.txt"));
    String line;
    while ((line = reader.readLine()) != null) {  // null means end of file
        System.out.println(line);
    }
    reader.close();    // ALWAYS close after reading!
} catch (IOException e) {
    System.out.println("Error reading file.");
}

Homework Pattern: Static Methods for File Operations

import java.util.Scanner;
import java.io.*;

public class NamesFile {

    static void writeNames() throws IOException {
        Scanner sc = new Scanner(System.in);
        BufferedWriter writer = new BufferedWriter(new FileWriter("names.txt"));
        System.out.println("Enter 5 names:");
        for (int i = 0; i < 5; i++) {
            String name = sc.nextLine();
            writer.write(name);
            writer.newLine();
        }
        writer.close();
    }

    static void readNames() throws IOException {
        BufferedReader reader = new BufferedReader(new FileReader("names.txt"));
        System.out.println("Names in the file:");
        String line;
        while ((line = reader.readLine()) != null) {
            System.out.println(line);
        }
        reader.close();
    }

    static void countLines() throws IOException {
        BufferedReader reader = new BufferedReader(new FileReader("names.txt"));
        int count = 0;
        while (reader.readLine() != null) {
            count++;
        }
        reader.close();
        System.out.println("Total lines: " + count);
    }

    public static void main(String[] args) {
        try {
            writeNames();
            readNames();
            countLines();
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}

6. ArrayList with Polymorphism

You can store child objects in an ArrayList declared with the parent type. This is powerful — you can call overridden methods on each element and get the correct child behavior.

ArrayList Syntax

import java.util.ArrayList;

// Declare and populate
ArrayList<Book> library = new ArrayList<Book>();

// Add objects (both child types work!)
library.add(new FictionBook("Harry Potter", "J.K. Rowling", "Fantasy"));
library.add(new FictionBook("Dune", "Frank Herbert", "Sci-Fi"));
library.add(new FictionBook("1984", "George Orwell", "Dystopia"));
library.add(new NonFictionBook("Sapiens", "Yuval Harari", "History"));
library.add(new NonFictionBook("Thinking Fast and Slow", "D. Kahneman", "Psychology"));
library.add(new NonFictionBook("A Brief History of Time", "S. Hawking", "Physics"));

// Iterate and call methods (polymorphism in action)
for (Book b : library) {
    b.displayInfo();                              // calls correct override
    System.out.println("Recommended for 16: " + b.isRecommendedForAge(16));
    System.out.println("---");
}

+methodName(param: Type): ReturnTypeMethod signature

How to implement from UML:

  1. Check if the class name is in italics → add abstract keyword
  2. Check the arrow direction → determine parent/child relationship
  3. Check for <<interface>> → use interface keyword and implements
  4. List all fields (private) with getters/setters
  5. Implement all methods — italic ones are abstract (no body)
  6. Constructors: no-arg + parameterized (use super() in child)

9. Full Code Examples for Exam Practice

Example A: Shape Hierarchy (Abstract Class Pattern)

abstract class Shape {
    private String color;

    public Shape(String color) { this.color = color; }
    public String getColor() { return color; }

    public abstract double getArea();
    public abstract double getPerimeter();

    public void displayInfo() {
        System.out.println("Color: " + color);
        System.out.printf("Area: %.2f%n", getArea());
        System.out.printf("Perimeter: %.2f%n", getPerimeter());
    }
}

class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double getArea() { return Math.PI * radius * radius; }

    @Override
    public double getPerimeter() { return 2 * Math.PI * radius; }
}

class Rectangle extends Shape {
    private double width, height;

    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }

    @Override
    public double getArea() { return width * height; }

    @Override
    public double getPerimeter() { return 2 * (width + height); }
}

// Main
import java.util.ArrayList;

public class ShapeMain {
    public static void main(String[] args) {
        ArrayList<Shape> shapes = new ArrayList<Shape>();
        shapes.add(new Circle("Red", 5.0));
        shapes.add(new Rectangle("Blue", 4.0, 6.0));

        for (Shape s : shapes) {
            s.displayInfo();
            System.out.println("---");
        }
    }
}

Example B: Interface with Multiple Types

interface Vehicle {
    void setSpeed(int speed);
    int getSpeed();
    void accelerate(int amount);
    void displayInfo();
}

class Car implements Vehicle {
    private String brand;
    private int speed;

    public Car(String brand, int speed) {
        this.brand = brand;
        this.speed = speed;
    }

    @Override public void setSpeed(int speed) { this.speed = speed; }
    @Override public int getSpeed() { return speed; }
    @Override public void accelerate(int amount) { speed += amount; }

    @Override
    public void displayInfo() {
        System.out.println(brand);
        System.out.println("Car");
        System.out.println(speed + " km/h");
    }
}

class Bicycle implements Vehicle {
    private String type;
    private int speed;

    public Bicycle(String type, int speed) {
        this.type = type;
        this.speed = speed;
    }

    @Override public void setSpeed(int speed) { this.speed = speed; }
    @Override public int getSpeed() { return speed; }
    @Override public void accelerate(int amount) { speed += amount; }

    @Override
    public void displayInfo() {
        System.out.println(type);
        System.out.println("Bicycle");
        System.out.println(speed + " km/h");
    }
}

public class VehicleMain {
    public static void main(String[] args) {
        Vehicle v1 = new Car("Toyota", 60);
        Vehicle v2 = new Bicycle("Mountain", 20);

        v1.accelerate(30);
        v2.accelerate(10);

        v1.displayInfo();
        System.out.println("---");
        v2.displayInfo();
    }
}

Example C: File I/O with Classes

import java.io.*;
import java.util.ArrayList;
import java.util.Scanner;

public class StudentManager {

    static void saveStudents(ArrayList<String> students) throws IOException {
        BufferedWriter writer = new BufferedWriter(new FileWriter("students.txt"));
        for (String s : students) {
            writer.write(s);
            writer.newLine();
        }
        writer.close();
        System.out.println("Data saved.");
    }

    static void loadStudents() throws IOException {
        BufferedReader reader = new BufferedReader(new FileReader("students.txt"));
        String line;
        System.out.println("Students:");
        while ((line = reader.readLine()) != null) {
            System.out.println(line);
        }
        reader.close();
    }

    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<String>();
        list.add("Alice - 2020001");
        list.add("Bob - 2020002");
        list.add("Charlie - 2020003");

        try {
            saveStudents(list);
            loadStudents();
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}
Common Mistakes to Avoid:
  • Forgetting import java.io.*; for File I/O
  • Forgetting import java.util.ArrayList; for ArrayLists
  • Not calling writer.close() or reader.close()
  • Trying to instantiate an abstract class or interface
  • Not overriding all abstract methods (compile error)
  • Using extends instead of implements for interfaces
  • Forgetting super() in child constructor when parent has a parameterized constructor
  • Using final or static on abstract methods
