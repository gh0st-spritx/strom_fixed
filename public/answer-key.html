Question 2 · Proof Techniques

12 points
(a)[6]
Let p: "n²−6n+5 is even", q: "n is odd". Prove p→q by proving the contrapositive ¬q→¬p, i.e. "n even ⟹ n²−6n+5 is odd."
Solution
Assume n is even, so n = 2k for some integer k. n² − 6n + 5 = 4k² − 12k + 5 = 2(2k² − 6k + 2) + 1 This is 2·(integer) + 1, so it is odd. We have shown ¬q → ¬p, so by contraposition p → q holds: if n²−6n+5 is even, then n is odd. ∎
(b)[6]
Solution
Suppose, for contradiction, that r is the smallest positive rational number. Since r > 0 is rational, r/2 is also rational (a ratio of integers) and positive, and r/2 < r. So r/2 is a positive rational number smaller than r — contra- dicting that r was the smallest. Hence no smallest positive rational number exists. ∎

(a)[4]
Solution Injective: suppose f(a)=f(b): 3a−2=3b−2 ⟹ 3a=3b ⟹ a=b. So f is injective.

Not surjective. Onto would require, for every m∈ℤ, an integer n with 3n−2=m, i.e. n=(m+2)/3. Take m=0: n=2/3 ∉ ℤ. Counterexample: 0 has no preimage.

Surjective: every real y has a real cube root x=∛y with g(x)=y.

g⁻¹(x) = ∛x
(c)[5]
Solution Define f: ℤ⁺ → (positive odd integers) by f(n) = 2n − 1.
Injective: f(n)=f(m) ⟹ 2n−1=2m−1 ⟹ n=m. Surjective: any positive odd integer t = 2k−1 for k=(t+1)/2 ∈ ℤ⁺, and f(k) = t.
f is a bijection ℤ⁺ → (positive odd integers), so the positive odd integers are countably infinite (cardinality ℵ₀). ∎

Question 5 · Induction

14 points
Claim
Solution
Let P(n): 1·1! + 2·2! + ... + n·n! = (n+1)! − 1 BASIS STEP (n=1): LHS = 1·1! = 1. RHS = 2! − 1 = 2 − 1 = 1. P(1) holds. INDUCTIVE HYPOTHESIS: Assume P(k): 1·1!+2·2!+...+k·k! = (k+1)! − 1, for some k≥1. INDUCTIVE STEP — show P(k+1): Σ(i=1..k+1) i·i! = [Σ(i=1..k) i·i!] + (k+1)·(k+1)! = (k+1)! − 1 + (k+1)·(k+1)! (by inductive hypothesis) = (k+1)!·[1 + (k+1)] − 1 = (k+1)!·(k+2) − 1 = (k+2)! − 1 This is exactly P(k+1). Since P(1) holds and P(k)→P(k+1) for all k≥1, by mathematical induction P(n) holds for every positive integer n. ∎
