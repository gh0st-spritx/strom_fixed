Also the midterm-bonus area — know this cold.

Predicate logic & quantifiers

DefinitionP(x) is a propositional function — becomes a proposition once x is bound by a quantifier or replaced with a domain value.
QuantifierSymbolTrue when
Universal∀x P(x)P(x) holds for every x in the domain
Existential∃x P(x)P(x) holds for some x
Uniqueness∃!x P(x)exactly one x works
De Morgan's for quantifiers¬∀x P(x) ≡ ∃x ¬P(x)   ¬∃x P(x) ≡ ∀x ¬P(x)
Nested quantifiers: order matters between unlike quantifiers. ∀x∃y P(x,y) ≠ ∃y∀x P(x,y) in general (e.g. P(x,y): x+y=0 over ℝ — the first is true, the second false). Same-type quantifiers commute freely: ∀x∀y ≡ ∀y∀x, ∃x∃y ≡ ∃y∃x.

Worked example — argument construction
Premises: "All men are mortal", "Socrates is a man" Let M(x): x is a man, R(x): x is mortal. 1. ∀x(M(x)→R(x)) premise 2. M(Socrates) premise 3. M(Socrates)→R(Socrates) UI on 1 4. R(Socrates) Modus Ponens on 2,3

Proof Techniques

Also the second midterm-bonus area.

TermMeaning
Theoremstatement proved true from definitions/axioms/other theorems
Lemmaa "helper" theorem used to prove a bigger theorem
Corollaryresult that follows directly from a theorem
Conjecturestatement believed true but not yet proved

Proving p → q

TrivialShow q is true outright — p→q holds regardless of p.
VacuousShow p is false — p→q holds automatically.
DirectAssume p true, chain reasoning to show q true.
Contraposition (indirect)Assume ¬q, show ¬p. Valid since ¬q→¬p ≡ p→q.
ContradictionTo prove statement p: assume ¬p, derive something false (often r∧¬r). Since ¬p⇒F is a tautology only if ¬p is false, p must hold.
Worked — contraposition
Claim: if 3n+2 is odd, n is odd. Contrapositive: if n is even, 3n+2 is even. Assume n=2k. Then 3n+2 = 6k+2 = 2(3k+1) — even. ∎ Since ¬q→¬p is proved, p→q holds.
Worked — contradiction (√2 irrational)
Suppose √2 = a/b in lowest terms (gcd(a,b)=1). Then a² = 2b² ⟹ a² even ⟹ a even ⟹ a=2c. So 4c² = 2b² ⟹ b² = 2c² ⟹ b even. Both a,b even contradicts gcd(a,b)=1. So √2 is irrational. ∎

Other proof strategies

Proof by casesSplit p1∨p2∨…∨pn → q into cases pi → q. Every case must be covered.
WLOG"Without loss of generality" — skip a case that is symmetric/identical in structure to one already done.
Constructive existenceExhibit a specific c with P(c) true.
Nonconstructive existenceProve some c must exist without naming it (often via contradiction).
CounterexampleTo disprove ∀x P(x), exhibit one c with P(c) false.
Uniqueness (∃!x P(x))Two parts: existence (find one x that works) + uniqueness (assume y also works, show y=x).
Biconditional p ↔ qProve both p→q and q→p (or chain "iff" equivalences directly).
Strategy order: try direct first → then contrapositive → then contradiction. Within a method, try forward reasoning (start from hypothesis) before backward reasoning (work back from goal).

Set basics (prerequisite)

SubsetA⊆B iff ∀x(x∈A→x∈B). ∅⊆S always.
Power set|P(A)| = 2|A|
Cartesian productA×B = {(a,b) | a∈A, b∈B}, |A×B|=|A||B|

Functions

Definitionf: A→B assigns exactly one element of B to each element of A. A = domain, B = codomain, f(A) = range (⊆ codomain).
PropertyDefinitionTo prove
Injective (1-1)f(a)=f(b) ⟹ a=bassume f(a)=f(b), derive a=b algebraically
Surjective (onto)∀b∈B ∃a∈A: f(a)=bpick arbitrary b, exhibit a in terms of b
Bijectiveinjective and surjectiveshow both; only bijections have inverses
Worked — is f(x)=x² onto ℤ→ℤ?
No: −1 has no preimage since x² ≥ 0 for all integers x. Counterexample suffices to disprove "onto."
Composition(f∘g)(x) = f(g(x)); domain requires range(g) ⊆ domain(f).
Floor / ceiling⌊x⌋ = largest integer ≤ x. ⌈x⌉ = smallest integer ≥ x.

Cardinality & countability

NotationMeaning
|A|=|B|a bijection A→B exists
|A|≤|B|an injection A→B exists
|A|<|B||A|≤|B| but not |A|=|B|
DefinitionA set is countable if finite, or in bijection with ℤ⁺ (countably infinite, cardinality ℵ₀). Otherwise uncountable.
To show countableExhibit a bijection with ℕ, or list all elements in a sequence a₁,a₂,a₃,…
ℤ is countableℚ⁺ is countablefinite strings over a finite alphabet are countable
Cantor diagonalizationProves ℝ (even just (0,1)) is uncountable — proof by contradiction. Assume a listing r₁,r₂,… of all reals in (0,1); build a new real that differs from rᵢ in the i-th decimal digit for every i ⟹ it's missing from the list ⟹ contradiction.
Hilbert's Grand Hotel: a countably-infinite hotel, fully booked, can still seat one more guest (shift everyone from room n to n+1) — intuition-builder for "countably infinite ≠ finite" arithmetic.

Sequences & Summations

DefinitionA sequence is a function from a subset of ℤ (usually ℕ or ℤ⁺) to a set S. Notation: aₙ is the n-th term.
Geometric progressionaₙ = a·rⁿ (a=initial term, r=common ratio)
Arithmetic progressionaₙ = a + n·d (d=common difference)

Recurrence relations

DefinitionExpresses aₙ in terms of earlier terms (a₀,…,aₙ₋₁), plus initial condition(s). Example: Fibonacci — f₀=0, f₁=1, fₙ=fₙ₋₁+fₙ₋₂.
Worked — forward substitution
aₙ = aₙ₋₁ + 3, a₁ = 2 a₂ = 2+3 a₃ = 2+3·2 a₄ = 2+3·3 …pattern: aₙ = 2 + 3(n−1)
Worked — backward substitution
aₙ = aₙ₋₁+3 = (aₙ₋₂+3)+3 = aₙ₋₂+3·2 = … = a₁+3(n−1) = 2+3(n−1)
Guess a closed form from the pattern, then confirm it with induction (Topic 5) — this is the standard exam combo.

Summation notation

FormulaValue
Sum 1..nΣᵢ₌₁ⁿ i = n(n+1)/2
Sum of squaresΣᵢ₌₁ⁿ i² = n(n+1)(2n+1)/6
Geometric series (r≠1)Σⱼ₌₀ⁿ rʲ = (rⁿ⁺¹−1)/(r−1)
Geometric series (r=1)Σⱼ₌₀ⁿ rʲ = n+1
Infinite geometric (|r|<1)Σⱼ₌₀^∞ rʲ = 1/(1−r)
Index shifting: Σᵢ₌₀ⁿ f(i) = Σₖ₌₁ⁿ⁺¹ f(k−1) (substitute k=i+1). Useful for deriving the geometric-series formula and for telescoping sums.

Induction & Recursion

Mathematical induction

TemplateTo prove ∀n≥n₀ P(n):
  1. Basis step: verify P(n₀).
  2. Inductive step: assume P(k) (the "inductive hypothesis") for arbitrary k≥n₀; prove P(k+1) follows.
Conclude ∀n≥n₀ P(n) holds (rule of inference: (P(1)∧∀k(P(k)→P(k+1))) → ∀n P(n)).
Worked — Σi = n(n+1)/2
Basis: n=1: 1 = 1·2/2 ✓ Inductive step: assume Σᵢ₌₁ᵏ i = k(k+1)/2. Σᵢ₌₁ᵏ⁺¹ i = k(k+1)/2 + (k+1) = (k+1)(k+2)/2 = (k+1)((k+1)+1)/2 ✓
Inequalities/divisibility follow the same template — just algebra differs. For n < 2ⁿ: assume k<2ᵏ, then k+1 < 2ᵏ+1 ≤ 2ᵏ+2ᵏ = 2ᵏ⁺¹.

Strong induction

TemplateBasis: P(n₀). Inductive step: assume P(n₀)∧…∧P(k) all hold, prove P(k+1). Use when P(k+1) may depend on any earlier term, not just P(k) (e.g. postage-stamp problems, "every integer >1 is a product of primes").
Math induction, strong induction, and the well-ordering property (every nonempty subset of ℤ⁺ has a least element) are logically equivalent — use whichever is easiest to set up.

Recursive definitions

DefinitionTwo parts: basis step (seed value/element) + recursive step (build new values/elements from existing ones). An implicit exclusion rule says nothing else is in the set.
Recursive function
f(0)=3 f(n+1)=2f(n)+3
Recursive set
Basis: 3∈S Recursive: x,y∈S ⟹ x+y∈S (this S = positive multiples of 3)

Structural induction

TemplateTo prove a property over a recursively-defined set/structure: (1) verify it for every basis-step element, (2) assume it for the pieces used in the recursive step, prove it for the newly built element. Standard use: full binary trees, well-formed formulas, strings over Σ*.

Relations

DefinitionA binary relation R from A to B is any subset of A×B. A relation on A is a subset of A×A. There are 2ⁿ² relations on a set of size n.

Properties (the exam staple)

PropertySymbolic testHow to disprove
Reflexive∀x∈A: (x,x)∈Rfind one a with (a,a)∉R
Symmetric(a,b)∈R → (b,a)∈Rfind (a,b)∈R with (b,a)∉R
Antisymmetric(a,b)∈R∧(b,a)∈R → a=bfind a≠b with both (a,b),(b,a)∈R
Transitive(a,b)∈R∧(b,c)∈R → (a,c)∈Rfind a,b,c with (a,b),(b,c)∈R but (a,c)∉R
Symmetric and antisymmetric are not opposites — a relation can be both (e.g. equality) or neither.
From a matrix MRReflexive: all-1 diagonal. Symmetric: M=Mᵀ. Antisymmetric: mᵢⱼ=1 ⟹ mⱼᵢ=0 for i≠j.
From a digraphReflexive: loop at every vertex. Symmetric: every edge has a matching reverse edge. Antisymmetric: no reverse-edge pairs. Transitive: edges x→y, y→z force an edge x→z.
Composition & powersR∘S: (x,z) if ∃y with (x,y)∈S,(y,z)∈R. Rⁿ defined inductively (R¹=R, Rⁿ⁺¹=Rⁿ∘R). R transitive ⟺ Rⁿ⊆R for all n≥1.

Equivalence relations

DefinitionReflexive + symmetric + transitive. Classic example: congruence mod m.
Equivalence classes[a]ᴿ = {x | (a,x)∈R}. Key theorem: aRb ⟺ [a]=[b] ⟺ [a]∩[b]≠∅. The equivalence classes always partition the set (disjoint, nonempty, union = whole set) — and conversely, every partition defines an equivalence relation.

Partial orderings

DefinitionReflexive + antisymmetric + transitive. (S,R) is called a poset. Symbol ≼ used generically.
Comparablea,b comparable if a≼b or b≼a.
Total orderevery pair comparable → "chain."
Hasse diagram = digraph of a poset with reflexive loops removed, transitive edges removed, and edges drawn pointing upward (arrowheads dropped).

Basics of Graphs

DefinitionGraph G=(V,E): nonempty vertex set V, edge set E. simple graphno loops/multi-edges multigraphmulti-edges ok pseudographloops + multi-edges ok digraphordered-pair (directed) edges

Degree & the Handshaking Theorem

Handshaking theoremΣᵥ deg(v) = 2|E| — so the sum of degrees is always even, and any graph has an even number of odd-degree vertices.
Directed graphs: Σ deg⁻(v) = Σ deg⁺(v) = |E| (in-degree sum = out-degree sum = edge count).

Special graphs

NameDescription
Kₙcomplete graph — every pair of n vertices joined
Cₙcycle on n vertices (n≥3)
Wₙwheel — Cₙ plus a hub connected to all n rim vertices
Qₙn-cube — 2ⁿ vertices (bit strings), edges between strings differing in 1 bit
BipartiteV splits into V₁,V₂ with every edge crossing between them (2-colorable)
Kₘ,ₙcomplete bipartite — every V₁ vertex joined to every V₂ vertex

Representing graphs

Adjacency matrixn×n zero-one matrix, 1 at (i,j) iff vᵢ~vⱼ. Symmetric for undirected simple graphs; not necessarily for digraphs.
Adjacency listeach vertex → list of neighbors. Better for sparse graphs.
Counting pathsThe (i,j) entry of Aʳ = number of length-r walks from vᵢ to vⱼ.

Isomorphism

DefinitionG₁≅G₂ if a bijection f:V₁→V₂ exists preserving adjacency both ways.
Invariants to check firstsame # vertices, same # edges, same degree sequence (sorted). If any differ, not isomorphic — no need to search for a mapping.

Connectivity

TermMeaning

Euler & Hamilton

Euler circuit/pathtraverses every edge exactly once. Circuit exists ⟺ connected & every vertex has even degree. Path (not circuit) exists ⟺ connected & exactly 2 vertices of odd degree.
Hamilton circuit/pathvisits every vertex exactly once. No simple iff-condition known. Sufficient (not necessary): Dirac — n≥3 and deg(v)≥n/2 ∀v ⟹ Hamilton circuit exists. Ore — deg(u)+deg(v)≥n for every nonadjacent pair ⟹ circuit exists.
