Question 1: Abstract Classes — Shape Hierarchy
ABSTRACT CLASS  MEDIUM

Problem Statement:

Consider the UML diagram below. Implement the Shape (abstract), Circle, and Rectangle classes:

Shape ───────────────────────────────── - color : String ───────────────────────────────── + Shape() + Shape(color: String) + getColor(): String + setColor(color: String): void + getArea(): double + displayInfo(): void Circle Rectangle ───────────────────────────── ───────────────────────────── - radius : double - width : double ───────────────────────────── - height : double + Circle() ───────────────────────────── + Circle(color: String, + Rectangle() radius: double) + Rectangle(color: String, + getRadius(): double width: double, + setRadius(r: double): void height: double) + getArea(): double + getWidth(): double + displayInfo(): void + getHeight(): double + getArea(): double + displayInfo(): void

Notes:

  • getArea() for Circle: π × radius²
  • getArea() for Rectangle: width × height
  • displayInfo() prints: Color, then Area (2 decimal places)
  • In main: create one Circle and one Rectangle, call displayInfo() on both. Take color and dimensions from user input.
✅ Complete Answer:
import java.util.Scanner;

abstract class Shape {
    private String color;

    public Shape() {}

    public Shape(String color) {
        this.color = color;
    }

    public String getColor() { return color; }
    public void setColor(String color) { this.color = color; }

    public abstract double getArea();
    public abstract void displayInfo();
}

class Circle extends Shape {
    private double radius;

    public Circle() {}

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    public double getRadius() { return radius; }
    public void setRadius(double radius) { this.radius = radius; }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public void displayInfo() {
        System.out.println("Color: " + getColor());
        System.out.printf("Area: %.2f%n", getArea());
    }
}

class Rectangle extends Shape {
    private double width;
    private double height;

    public Rectangle() {}

    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }

    public double getWidth() { return width; }
    public double getHeight() { return height; }

    @Override
    public double getArea() {
        return width * height;
    }

    @Override
    public void displayInfo() {
        System.out.println("Color: " + getColor());
        System.out.printf("Area: %.2f%n", getArea());
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter circle color: ");
        String c1 = sc.nextLine();
        System.out.print("Enter circle radius: ");
        double r = sc.nextDouble();
        sc.nextLine();

        System.out.print("Enter rectangle color: ");
        String c2 = sc.nextLine();
        System.out.print("Enter width: ");
        double w = sc.nextDouble();
        System.out.print("Enter height: ");
        double h = sc.nextDouble();

        Circle circle = new Circle(c1, r);
        Rectangle rect = new Rectangle(c2, w, h);

        System.out.println("--- Circle ---");
        circle.displayInfo();

        System.out.println("--- Rectangle ---");
        rect.displayInfo();
    }
}
This is the most likely exam question pattern — abstract class with two concrete subclasses, getters/setters, abstract methods overridden differently in each subclass.
Question 2: Abstract Classes + ArrayList (Lab Homework Pattern)
ABSTRACT + ARRAYLIST  HIGH PROBABILITY

Problem Statement:

Using the Book, FictionBook, and NonFictionBook classes from the lab:

  • Create an ArrayList<Book> in main.
  • Add 3 FictionBook objects and 3 NonFictionBook objects.
  • Iterate through the ArrayList: print each book's info, then print whether it is recommended for a 16-year-old.
✅ Complete Answer:
import java.util.ArrayList;

abstract class Book {
    private String name;
    private String author;

    public Book() {}
    public Book(String name, String author) {
        this.name = name;
        this.author = author;
    }

    public void setName(String name) { this.name = name; }
    public String getName() { return name; }
    public void setAuthor(String author) { this.author = author; }
    public String getAuthor() { return author; }

    public abstract void displayInfo();
    public abstract boolean isRecommendedForAge(int age);
}

class FictionBook extends Book {
    private String genre;

    public FictionBook() {}
    public FictionBook(String name, String author, String genre) {
        super(name, author);
        this.genre = genre;
    }

    public void setGenre(String genre) { this.genre = genre; }
    public String getGenre() { return genre; }

    @Override
    public void displayInfo() {
        System.out.println(getName());
        System.out.println(getAuthor());
        System.out.println(genre);
    }

    @Override
    public boolean isRecommendedForAge(int age) {
        return age >= 14;
    }
}

class NonFictionBook extends Book {
    private String subject;

    public NonFictionBook() {}
    public NonFictionBook(String name, String author, String subject) {
        super(name, author);
        this.subject = subject;
    }

    public void setSubject(String subject) { this.subject = subject; }
    public String getSubject() { return subject; }

    @Override
    public void displayInfo() {
        System.out.println(getName());
        System.out.println(getAuthor());
        System.out.println(subject);
    }

    @Override
    public boolean isRecommendedForAge(int age) {
        return age >= 18;
    }
}

public class Main {
    public static void main(String[] args) {
        ArrayList<Book> library = new ArrayList<Book>();

        // 3 Fiction Books
        library.add(new FictionBook("Harry Potter", "J.K. Rowling", "Fantasy"));
        library.add(new FictionBook("Dune", "Frank Herbert", "Sci-Fi"));
        library.add(new FictionBook("1984", "George Orwell", "Dystopia"));

        // 3 Non-Fiction Books
        library.add(new NonFictionBook("Sapiens", "Yuval Noah Harari", "History"));
        library.add(new NonFictionBook("Thinking Fast and Slow", "D. Kahneman", "Psychology"));
        library.add(new NonFictionBook("A Brief History of Time", "S. Hawking", "Physics"));

        for (Book b : library) {
            b.displayInfo();
            System.out.println("Recommended for 16: " + b.isRecommendedForAge(16));
            System.out.println("---");
        }
    }
}
Expected output snippet: FictionBooks print "Recommended for 16: true" (age 16 ≥ 14). NonFictionBooks print "Recommended for 16: false" (age 16 < 18).

Question 4: File I/O — Write and Read
FILE I/O  MEDIUM

Problem Statement:

Write a program that:

  • Takes Name, Student ID, and Department from the user.
  • Writes the data to a file named student.txt.
  • Displays: Student information saved successfully.
  • Then reads and displays all information from student.txt.
  • If the file cannot be read, display an appropriate error message.
✅ Complete Answer:
import java.util.Scanner;
import java.io.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter name: ");
        String name = sc.nextLine();
        System.out.print("Enter student ID: ");
        String id = sc.nextLine();
        System.out.print("Enter department: ");
        String dept = sc.nextLine();

        // Write to file
        try {
            BufferedWriter writer = new BufferedWriter(new FileWriter("student.txt"));
            writer.write("Name: " + name);
            writer.newLine();
            writer.write("ID: " + id);
            writer.newLine();
            writer.write("Department: " + dept);
            writer.close();
            System.out.println("Student information saved successfully.");
        } catch (IOException e) {
            System.out.println("Unable to save file.");
        }

        // Read from file
        try {
            BufferedReader reader = new BufferedReader(new FileReader("student.txt"));
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
            reader.close();
        } catch (IOException e) {
            System.out.println("Error reading file.");
        }
    }
}
Key things examiners check: correct import, BufferedWriter/Reader wrapping FileWriter/Reader, newLine(), closing streams, proper try-catch.
Question 5: File I/O — Static Methods (Homework Pattern)
FILE I/O + METHODS  MEDIUM

Problem Statement:

Write a program with three static methods called from main:

  • writeNames() — takes 5 names from user and writes each to a new line in names.txt
  • readNames() — reads and displays all names from names.txt, preceded by Names in the file:
  • countLines() — counts and displays total number of lines: Total lines: 5
✅ Complete Answer:
import java.util.Scanner;
import java.io.*;

public class Main {

    static void writeNames() throws IOException {
        Scanner sc = new Scanner(System.in);
        BufferedWriter writer = new BufferedWriter(new FileWriter("names.txt"));
        System.out.println("Enter 5 names:");
        for (int i = 0; i < 5; i++) {
            String name = sc.nextLine();
            writer.write(name);
            writer.newLine();
        }
        writer.close();
    }

    static void readNames() throws IOException {
        BufferedReader reader = new BufferedReader(new FileReader("names.txt"));
        System.out.println("Names in the file:");
        String line;
        while ((line = reader.readLine()) != null) {
            System.out.println(line);
        }
        reader.close();
    }

    static void countLines() throws IOException {
        BufferedReader reader = new BufferedReader(new FileReader("names.txt"));
        int count = 0;
        while (reader.readLine() != null) {
            count++;
        }
        reader.close();
        System.out.println("Total lines: " + count);
    }

    public static void main(String[] args) {
        try {
            writeNames();
            readNames();
            countLines();
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}
When using throws IOException in a method, the caller (main) must wrap it in try-catch.
Question 6: Interface — Custom Domain (Most Likely Exam Variant)
INTERFACE  VERY HIGH PROBABILITY

Problem Statement:

Consider the following interface and implement two classes from it:

<<interface>> Employee ──────────────────────────────── + setName(name: String): void + getName(): String + getSalary(): double + work(): void + displayInfo(): void FullTimeEmployee PartTimeEmployee ──────────────────────── ──────────────────────── - name : String - name : String - salary : double - hourlyRate : double ──────────────────────── - hoursWorked : int + FullTimeEmployee() ──────────────────────── + FullTimeEmployee( + PartTimeEmployee() name: String, + PartTimeEmployee( salary: double) name: String, + getSalary(): double hourlyRate: double, + work(): void hoursWorked: int) + displayInfo(): void + getSalary(): double + work(): void + displayInfo(): void

Notes:

  • FullTimeEmployee getSalary(): returns fixed salary
  • PartTimeEmployee getSalary(): returns hourlyRate × hoursWorked
  • work(): FullTime prints "[name] is working full time", PartTime prints "[name] is working part time"
  • displayInfo(): prints name, type, salary (each on new line)
  • In main: create 2 of each, call work() and displayInfo() on all.
✅ Complete Answer:
public class Main {
    public static void main(String[] args) {
        FullTimeEmployee fte1 = new FullTimeEmployee("Alice", 50000.0);
        FullTimeEmployee fte2 = new FullTimeEmployee("Bob", 60000.0);
        PartTimeEmployee pte1 = new PartTimeEmployee("Charlie", 15.0, 80);
        PartTimeEmployee pte2 = new PartTimeEmployee("Diana", 20.0, 60);

        fte1.work();  fte1.displayInfo();  System.out.println("---");
        fte2.work();  fte2.displayInfo();  System.out.println("---");
        pte1.work();  pte1.displayInfo();  System.out.println("---");
        pte2.work();  pte2.displayInfo();  System.out.println("---");
    }
}

interface Employee {
    void setName(String name);
    String getName();
    double getSalary();
    void work();
    void displayInfo();
}

class FullTimeEmployee implements Employee {
    private String name;
    private double salary;

    public FullTimeEmployee() {}
    public FullTimeEmployee(String name, double salary) {
        this.name = name;
        this.salary = salary;
    }

    @Override public void setName(String name) { this.name = name; }
    @Override public String getName() { return name; }
    @Override public double getSalary() { return salary; }

    @Override
    public void work() {
        System.out.println(name + " is working full time");
    }

    @Override
    public void displayInfo() {
        System.out.println(name);
        System.out.println("Full Time");
        System.out.println(salary);
    }
}

class PartTimeEmployee implements Employee {
    private String name;
    private double hourlyRate;
    private int hoursWorked;

    public PartTimeEmployee() {}
    public PartTimeEmployee(String name, double hourlyRate, int hoursWorked) {
        this.name = name;
        this.hourlyRate = hourlyRate;
        this.hoursWorked = hoursWorked;
    }

    @Override public void setName(String name) { this.name = name; }
    @Override public String getName() { return name; }
    @Override public double getSalary() { return hourlyRate * hoursWorked; }

    @Override
    public void work() {
        System.out.println(name + " is working part time");
    }

    @Override
    public void displayInfo() {
        System.out.println(name);
        System.out.println("Part Time");
        System.out.println(getSalary());
    }
}
The examiner will change the theme (Employee, Vehicle, Appliance, Animal...) but the structure is ALWAYS the same. Master this template and adapt the field names and logic.
Bonus: Abstract Class with Scanner Input (Mixed)
BONUS PATTERN

Quick Template for any Abstract-class + User Input question:

import java.util.Scanner;

abstract class Vehicle {
    private String brand;
    private int year;

    public Vehicle() {}
    public Vehicle(String brand, int year) {
        this.brand = brand;
        this.year = year;
    }

    public String getBrand() { return brand; }
    public int getYear() { return year; }

    public abstract double getFuelEfficiency();  // abstract
    public abstract void displayInfo();           // abstract
}

class Car extends Vehicle {
    private double kmPerLitre;

    public Car(String brand, int year, double kmPerLitre) {
        super(brand, year);
        this.kmPerLitre = kmPerLitre;
    }

    @Override
    public double getFuelEfficiency() { return kmPerLitre; }

    @Override
    public void displayInfo() {
        System.out.println(getBrand());
        System.out.println("Car - " + getYear());
        System.out.printf("Fuel Efficiency: %.1f km/L%n", kmPerLitre);
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Brand: "); String b = sc.nextLine();
        System.out.print("Year: ");  int y = sc.nextInt();
        System.out.print("KM/L: ");  double k = sc.nextDouble();

        Car car = new Car(b, y, k);
        car.displayInfo();
    }
}
Exam Strategy: Read the UML first. Identify: (1) which class is abstract (italics), (2) which methods are abstract (italics/no body), (3) what the arrow direction is. Write all classes top-to-bottom: abstract parent first, then concrete children, then main.
