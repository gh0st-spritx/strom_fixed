Question 4

8 points
Solution — direct proof
Fact used: a product of integers is odd only if every factor is odd (contrapositive: if some factor is even, the product is even). Assume a²(b²−2b) is odd. It is a product of a² and (b²−2b), so both factors must be odd: (i) a² odd ⟹ a is odd. (if a were even, a=2k, then a²=4k² is even — contradiction) (ii) b²−2b = b(b−2) odd ⟹ both b and (b−2) are odd, so in particular b is odd. (b and b−2 always share the same parity, since they differ by 2 — consistent with both being odd here.) Hence both a and b are odd. ∎

Question 5

8 points
Solution
(→) Direct proof: assume n even, n=2k. n²−2n = 4k²−4k = 2(2k²−2k), which is even. (←) Proof by contraposition: assume n is odd, n=2k+1. Show n²−2n is odd. n²−2n = (2k+1)² − 2(2k+1) = 4k²+4k+1 − 4k−2 = 4k² − 1 = 2(2k²−1) + 1, which is odd. So ¬(n even) → ¬(n²−2n even), i.e. by contraposition, n²−2n even → n even. Both directions hold, so n is even ⟺ n²−2n is even. ∎

Question 6

8 points
Solution
Since A and B are countably infinite, list them as sequences: A = a1, a2, a3, ... B = b1, b2, b3, ... Define g: ℤ⁺ → A∪B by interleaving: g(2k−1) = ak, g(2k) = bk, for k = 1,2,3,... Every element of A∪B is some ai or bi, so it appears as g(2i−1) or g(2i) — g is a surjection from ℤ⁺ onto A∪B (possibly hitting shared elements twice, which is harmless). A set that is the image of a surjection from ℤ⁺ can be listed in a sequence (skip repeats), so A∪B is countable. ∎

Induction & recursion

Question 10

14 points
Solution
Let P(n): n = 3a + 5b for some nonnegative integers a,b. BASIS STEP — verify P(8), P(9), P(10): P(8): 8 = 3(1) + 5(1) P(9): 9 = 3(3) + 5(0) P(10): 10 = 3(0) + 5(2) INDUCTIVE HYPOTHESIS: Assume P(j) holds for every j with 8 ≤ j ≤ k, for some k ≥ 10. INDUCTIVE STEP — show P(k+1): Since k ≥ 10, we have k−2 ≥ 8, so P(k−2) is covered by the inductive hypothesis: k−2 = 3a + 5b for some nonnegative a,b. Then: k+1 = (k−2) + 3 = 3a + 5b + 3 = 3(a+1) + 5b which is of the required form (a+1 ≥ 0, b ≥ 0), so P(k+1) holds. By strong induction, P(n) holds for every integer n ≥ 8. ∎

Question 11

10 points
Solution — structural induction
Let len(w) denote the length of string w. BASIS STEP: The only basis element is "()", and len("()") = 2, which is even. RECURSIVE STEP: Assume w ∈ P has even length, say len(w) = 2m (inductive hypothesis). Each recursive rule adds exactly one pair of parentheses — 2 characters — to w: len(()w) = 2 + len(w) = 2 + 2m = 2(m+1) — even len((w)) = 2 + len(w) = 2 + 2m = 2(m+1) — even len(w()) = len(w) + 2 = 2m + 2 = 2(m+1) — even So every string built from w in the recursive step also has even length. By structural induction, every string in P has even length. ∎

(a)[5]
Solution — combinatorial proof
Let T be a set with n elements, fix one element a ∈ T, and let S = T − {a} (so |S| = n−1). Count the r-element subsets of T two ways: Directly: there are C(n,r) such subsets. By cases on whether a is included: • subsets containing a: choose the remaining r−1 elements from S → C(n−1,r−1) ways • subsets not containing a: choose all r elements from S → C(n−1,r) ways These cases are disjoint and exhaustive, so the count is C(n−1,r−1) + C(n−1,r). Both counts describe the same set of subsets, so: C(n,r) = C(n−1,r−1) + C(n−1,r) ∎
