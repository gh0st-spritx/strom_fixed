ABSTRACT CLASS

Rules

  • CANNOT instantiate (no new AbstractClass())
  • Must be extended by a subclass
  • Can have abstract + concrete methods
  • Can have constructors + fields
  • Abstract methods: no body, end with ;
  • No final/static on abstract methods
  • UML: italics = abstract class/method

Syntax

abstract class Animal {
  private String name;

  public Animal() {}
  public Animal(String name) { this.name = name; }

  public String getName() { return name; }
  public void setName(String n) { name = n; }

  public abstract void makeSound();   // NO body
  public abstract String getType();
}

class Dog extends Animal {
  public Dog(String name) {
    super(name);    // call parent constructor
  }

  @Override
  public void makeSound() {
    System.out.println(getName() + ": Woof!");
  }

  @Override
  public String getType() { return "Dog"; }
}

Book Example Quick Reference

  • FictionBook: isRecommendedForAge() → age >= 14
  • NonFictionBook: isRecommendedForAge() → age >= 18
  • displayInfo() prints name, author, genre/subject (each on new line)

INTERFACE

Rules

  • CANNOT instantiate
  • Use implements (not extends) in class
  • Class CAN implement MULTIPLE interfaces
  • All methods: public abstract by default
  • All variables: public static final by default
  • Implementing class MUST override ALL methods

Syntax

interface Playable {
  void play();           // public abstract by default
  void stop();
  String getName();
}

class Guitar implements Playable {
  private String name;

  public Guitar(String name) { this.name = name; }

  @Override
  public void play() {
    System.out.println(name + " is playing");
  }
  @Override
  public void stop() {
    System.out.println(name + " stopped");
  }
  @Override
  public String getName() { return name; }
}

// Multiple interfaces:
class Piano implements Playable, Tunable { ... }

FILE I/O

import java.io.*;   // ALWAYS needed

Write to File

try {
  BufferedWriter writer = new BufferedWriter(
      new FileWriter("file.txt"));   // overwrites
  writer.write("Hello");
  writer.newLine();
  writer.write("World");
  writer.close();   // MUST close!
} catch (IOException e) {
  System.out.println("Error: " + e.getMessage());
}

Append Mode

new BufferedWriter(new FileWriter("file.txt", true))
// true = append, false/omit = overwrite

Read from File

try {
  BufferedReader reader = new BufferedReader(
      new FileReader("file.txt"));
  String line;
  while ((line = reader.readLine()) != null) {
    System.out.println(line);
  }
  reader.close();   // MUST close!
} catch (IOException e) {
  System.out.println("Error reading.");
}

Create File

File f = new File("file.txt");
if (f.createNewFile()) System.out.println("Created");
else System.out.println("Already exists");

Count Lines

BufferedReader r = new BufferedReader(new FileReader("f.txt"));
int count = 0;
while (r.readLine() != null) count++;
r.close();
System.out.println("Total lines: " + count);

EXCEPTION HANDLING

try-catch-finally

try {
  // risky code here
  int x = 10 / 0;
} catch (ArithmeticException e) {
  System.out.println(e.getMessage());
} catch (Exception e) {   // catch-all
  System.out.println("Error: " + e.getMessage());
} finally {
  // always runs (cleanup here)
}

throws declaration

void readFile() throws IOException {
  // let caller handle the exception
}

Common Exceptions

  • IOException — file errors
  • FileNotFoundException — missing file
  • ArithmeticException — divide by 0
  • NullPointerException — null reference
  • NumberFormatException — bad int parse

ARRAYLIST WITH POLYMORPHISM

import java.util.ArrayList;
// Parent-type ArrayList holding child objects
ArrayList<Book> books = new ArrayList<Book>();
books.add(new FictionBook("HP", "JKR", "Fantasy"));
books.add(new NonFictionBook("Sapiens", "YNH", "History"));

// for-each loop
for (Book b : books) {
  b.displayInfo();
  System.out.println(b.isRecommendedForAge(16));
  System.out.println("---");
}

// check type inside loop
if (b instanceof FictionBook) { ... }

// other methods
books.size();       // number of elements
books.get(i);       // get element at index i
books.remove(i);    // remove at index i

POLYMORPHISM QUICK REFERENCE

Method Overriding

class Parent {
  void show() { System.out.println("Parent"); }
}
class Child extends Parent {
  @Override
  void show() { System.out.println("Child"); }
}
// Parent reference, Child object
Parent p = new Child();
p.show();  // prints "Child" (runtime binding)

super keyword

// Call parent constructor
super(arg1, arg2);       // must be FIRST line

// Call parent method
super.methodName();
